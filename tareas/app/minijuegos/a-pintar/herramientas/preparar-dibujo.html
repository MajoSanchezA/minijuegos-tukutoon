Preparar dibujo para TukuToon

Herramienta interna. Soltá el PNG de línea que mandó el diseñador: se valida contra la guía de entrega, se te muestran las zonas que el motor va a poder pintar, y te genera la página lista para guardar — con la imagen ya incrustada, sin tocar base64 a mano.

1 El PNG del dibujo

De línea, horizontal, fondo blanco, sin colorear.

🖼️
Arrastrá el PNG acá o hacé clic para buscarlo

2 Revisión

Esto es exactamente lo que va a ver el motor del juego.

    Vista previa

    En Zonas, cada área que el balde puede rellenar por separado sale de un color distinto. Si dos partes que deberían ser distintas salen del mismo color, hay un contorno abierto entre las dos. Tocá cualquier zona para medirla.

    3 Datos del dibujo

    El nombre corto define la carpeta, el archivo y el id del menú.

    Si el diseñador mandó la versión a color del mismo dibujo, cargala ahí y se sacan solos los 9 colores principales.

    4 Listo para guardar

    Dos archivos y una línea de texto. Nada más.
