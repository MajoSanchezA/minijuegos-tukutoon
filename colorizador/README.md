# Coloriza

Herramienta independiente para cambiar el tono de una imagen desde el navegador.

Abre `index.html` directamente en un navegador moderno. También puedes servir la carpeta con cualquier servidor estático.

Las imágenes se procesan localmente. La descarga se genera como PNG y conserva la transparencia del archivo original. Para imágenes grandes se limita la vista de trabajo a 3000 píxeles en su lado más largo.
